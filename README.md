## ⚡ О проекте

**FROST CLI 2.0** — автономный терминальный AI-агент и интерактивный CLI-клиент нового поколения. Разработан для решения сложных инженерных, системных и кодовых задач с полным прямым доступом к компьютеру и поддержкой глубокого пошагового мышления (Chain-of-Thought).

В отличие от стандартных чат-ботов, **FROST CLI** работает прямо в вашей операционной системе: создаёт и редактирует файлы, запускает PowerShell-скрипты, управляет системными процессами и анализирует проектные директории в реальном времени.

## ✨ Ключевые возможности

- 🧠 **Автономный AI-инженер (Full PC Access)**:
  - Выполнение системных PowerShell команд (`run_powershell`).
  - Создание и редактирование файлов на диске (`write_file`, `read_file`).
  - Исследование файловой структуры (`list_directory`).
  - Архитектурное проектирование в 1 команду: `/plan <задача>`.

- 📑 **Система вкладок чатов (Tabs)**:
  - Работайте сразу над несколькими задачами в одном окне без потери контекста.
  - У каждого чата своя независимая история, выбранная модель и уровень мощности.
  - Автоматическое наименование вкладок по первому запросу (как в Cursor / ChatGPT).
  - Мгновенное переключение без спама в консоль.

- 🎨 **Кибер-дизайн и плавная тёмно-красная эстетика**:
  - Шрифт в стиле Claude Code с изометрическими двойными тенями (`╗`, `╝`, `═`, `║`).
  - Плавный 48-шаговый градиент в глубоких тёмно-красных / рубиновых тонах с косинусным сглаживанием.
  - Киберпанк-монолит с интерактивной HUD-телеметрией системы.

- 🔥 **Трёхступенчатая регулировка мощности (Thinking Power)**:
  - **High** — 16K токенов контекста, максимальное глубокое мышление.
  - **Medium** — 8K токенов, сбалансированный режим для повседневных задач.
  - **Fast** — 4K токенов, моментальный отклик с минимальной задержкой.

- 📦 **100% Single-Window & Native Standalone Binary**:
  - Единый автономный `.exe` файл (Node.js Single Executable Application).
  - Вшита собственная нативная иконка приложения в тёмно-красном стиле FROST.
  - Никаких лишних всплывающих окон, консольных миганий и сторонних зависимостей.

- 🌐 **Интеграция с DSH Web и шлюзами Tokify / FunPay**:
  - Автоматический скрытый запуск фонового веб-демона на порту `3080`.
  - Управление токенами, онлайн-проверка баланса и квот с прогресс-баром (`/stats`, `/tokens`).

## ⌨️ Горячие клавиши

| Горячая клавиша | Действие |
| :--- | :--- |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> *(или F2)* | Мгновенно сменить модель активного чата |
| <kbd>Ctrl</kbd> + <kbd>Tab</kbd> *(или F3)* | Мгновенно переключить уровень мощности (High / Med / Fast) |
| <kbd>Ctrl</kbd> + <kbd>T</kbd> | Создать новую вкладку чата |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Закрыть текущую вкладку |
| <kbd>Alt</kbd> + <kbd>1</kbd> … <kbd>9</kbd> | Быстрый переход на вкладку с номером 1-9 |
| <kbd>F6</kbd> / <kbd>F7</kbd> | Следующая / Предыдущая вкладка |

## 💬 Встроенные команды чата

```bash
/help              # Справка по всем возможностям и хоткеям
/new [имя]         # Создать новую вкладку (например: /new Рефакторинг)
/tab [1-9|next]    # Переключиться на вкладку по номеру
/close [номер]     # Закрыть вкладку
/rename <имя>      # Переименовать текущую вкладку
/tabs              # Список всех открытых вкладок и статистика сообщений
/power [1-3]       # Выбор уровня мощности: 1 (High), 2 (Medium), 3 (Fast)
/model [номер|имя] # Просмотр или переключение AI-модели
/plan <задача>     # Создание исчерпывающего архитектурного плана с исполнением
/stats             # Баланс токенов, остаток пакета и лимиты запросов
/tokens            # Список сохранённых токенов прямо в чате
/token <номер>     # Переключение активного токена
/web               # Проверить статус фонового сервиса DSH Web (:3080)
/clear             # Очистить историю активного чата и обновить экран
/exit              # Завершение работы
```

## 🚀 Установка и запуск

### Вариант 1. Скачать готовый `.exe` (Рекомендуется)
Скачайте последний релиз **`FROST-CLI.exe`** из раздела [Releases](https://github.com/fffwwwoo/FROST-CLI/releases) и запустите двойным кликом.

### Вариант 2. Запуск из исходного кода
```bash
# Клонировать репозиторий
git clone https://github.com/fffwwwoo/FROST-CLI.git
cd FROST-CLI

# Установить зависимости
npm install

# Запуск интерактивного меню лаунчера
node app.js

# Запуск прямо в режим чата
node app.js chat
```

### Сборка единого .exe файла (Standalone Binary):
```bash
node build.js
```
Скрипт автоматически упакует приложение через `esbuild`, сгенерирует SEA-блоб, встроит кастомную `.ico` иконку в PE-ресурсы и соберёт переносимый `FROST-CLI.exe`.
